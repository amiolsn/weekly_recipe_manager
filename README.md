🍴 1週間献立マネージャー (Weekly Recipe Manager)
楽天レシピAPIを活用し、主菜・副菜のバランスを考慮した5日分の献立と買い物リストを自動生成するフルスタックWebアプリケーションです。

📝 開発の経緯
このプロジェクトは、私自身の日常生活における「名もなき家事」の負担を軽減したいという思いから始まりました。

抱えていた課題
献立決定の心理的負荷: 毎日「今日何作ろう？」とゼロから考える作業が大きなストレス。

買い物の非効率性: 複数のレシピで重複する材料を整理してメモするのが手間。

献立のマンネリ化: 忙しいとメニューが固定化され、栄養やバリエーションが乏しくなる。

解決のアプローチ 楽天レシピの膨大なデータから自動で組み合わせを提案し、材料をシステム的に集約することで、「悩む時間」を「料理を楽しむ時間」へと変えることを目指しました。

🚀 主な機能
献立自動生成: 肉・魚・副菜をバランスよく5日分選出。

買い物リスト作成: 全レシピの材料をスキャンし、重複を自動で排除して集約。

チェックリスト: 買い物中にブラウザ上でチェックを入れられる便利なUI。

リアルタイム連携: 楽天レシピAPIから最新のランキングデータを取得。

🛠 技術スタック
Backend
Language: Python 3.x

Framework: Flask (Web API サーバー)

Libraries: Requests, Flask-CORS, python-dotenv

Processing: 正規表現 (re) によるデータクレンジング

Frontend
Language: JavaScript (ES6+), HTML5, CSS3

Techniques: 非同期通信 (fetch, async/await), DOM操作, レスポンシブデザイン

💡 こだわり・工夫した点
1. APIレート制限への堅牢な対応
楽天APIの「1秒間に1リクエスト」という制約に対し、サーバー側で厳密な待機時間を制御。Status 429エラーを未然に防ぎ、安定したデータ取得を可能にしました。

2. インタラクティブなUX設計
API通信の待機時間（約15〜20秒）にユーザーが不安を感じないよう、JavaScriptでボタンの状態を「作成中...」へ動的に変更し、進捗を可視化しました。

3. 高度なデータクレンジング
APIから取得した生の材料データに含まれる記号を正規表現で一括除去。買い物リストとして最も見やすい形に整形して出力します。

📂 セットアップ方法
1. リポジトリのクローン
git clone [https://github.com/あなたのユーザー名/リポジトリ名.git](https://github.com/あなたのユーザー名/リポジトリ名.git)
cd リポジトリ名
2. ライブラリのインストール
pip install -r requirements.txt
3. APIキーの設定
プロジェクトのルートディレクトリに .env という名前のファイルを作成し、楽天デベロッパーIDを記述してください。

RAKUTEN_APP_ID=あなたのアプリID
4. 実行
以下の手順でアプリケーションを起動します。

Backend（Pythonサーバー）の起動 python main.py

Frontendの表示 サーバー起動後、ブラウザで index.html を開いてください。

⚠️ 注意事項
本アプリはローカル環境（localhost:5000）での動作を前提としています。

楽天レシピAPIの利用規約に従ってご利用ください。
